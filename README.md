## 🚀 Featured Projects

### 🎧 Smart Hearing Aid — Beamforming & Noise Reduction
**Final Year Project · 2026 · In Progress**

- Developing a portable hearing-assistance prototype with **ESP32-S3** and **3 INMP441 I2S MEMS microphones**.
- Exploring **DOA/TDOA sound localization, three-microphone beamforming, and DSP noise reduction** to improve speech intelligibility in noisy environments.
- Using a **UDA1334A DAC** for I2S audio output to wired earphones.
- Designing a custom PCB in **KiCad** and integrating battery power with a **TP4056 charging module**.

**Tools:** ESP32-S3 · INMP441 · UDA1334A · I2S · DSP · KiCad

### 🕹️ VGA Pong — RTL Game Implementation
**Personal Project · Verilog · Xilinx Vivado**

- Implemented a Pong game entirely in RTL, without software rendering.
- Organized the design into four modules: video sync generator, graphics/physics logic, top-level integration, and testbench.
- Generated **640×480 VGA at 60 Hz** and implemented ball collision/boundary logic with velocity reversal.
- Verified timing and logic through behavioral simulation in Vivado.

**Tools:** Verilog · RTL · FPGA · Xilinx Vivado · VGA
